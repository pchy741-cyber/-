# 기능 동결 헌장 (Feature Freeze Charter)

**발효일**: v28 배포 완료 시점
**적용 범위**: ai-auto-bot 전체 코드베이스

---

## 1. 원칙

v28 이후 **기능 추가를 영구 동결**한다.
이후 모든 작업은 아래 세 범주로만 허용된다:

1. **검증** — 기존 기능의 정확성·안정성 확인 (테스트, 모니터링, 로깅 강화)
2. **측정** — 성과 지표 수집·분석 (score_accuracy, slippage_ledger, PnL 통계)
3. **증액** — 검증된 전략의 자본 배분 확대

---

## 2. 허용·금지 기준

### 2-a. 허용 (동결 예외 아님 — 원래 가능)
- 버그 수정 (기존 동작이 의도와 다른 경우)
- 보안 패치
- 의존성 업데이트
- 로깅·모니터링 강화
- 리팩토링 (외부 동작 변경 없음)
- 파라미터 튜닝 (기존 상수 조정)

### 2-b. 금지 (동결 대상)
- 새로운 매매 전략 추가
- 새로운 데이터 소스 연동
- 새로운 API 엔드포인트 (측정·검증 용도 제외)
- 새로운 알림 채널
- UI 기능 확장

### 2-c. 예외 절차
동결 기능을 추가하려면:
1. **4주 재판 (Trial)** 실시
2. PAPER_SHADOW 모드에서만 실행
3. 재판 중 파라미터 변경 금지 (변경 시 시계 리셋)
4. 마찰 차감 순기대값을 기존 동등 전략과 동기간 비교
5. 표본 30건+ AND 순기대값 우위 → 정식 승격 (기존 로직 교체, 순증 아님)
6. 미달 → 폐지, 미련 없이

## 4. 해제 조건

이 헌장은 아래 조건 **모두** 충족 시에만 해제 가능:
- 실전 운용 90일+ 경과
- 월간 순수익 양수 3개월 연속
- MDD < -15% 미달성
- 운영자 서면 승인
